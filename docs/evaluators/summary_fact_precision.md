# SummaryFactPrecision

**Registry name** `summary_fact_precision` · **Type** Reference-based LLM judge, ratio score · **Module** `evals/evaluators/summary_facts.py` · **Prompt versions** `summary_facts/extract/v1`, `summary_facts/verify/v1` · **Default threshold** 1.0

## What it checks

Precision of an LLM summary against a human reference summary: the share of the LLM summary's claims that the reference supports. Answers *did the LLM summary say anything the reference does not support?*

## Inputs

| Field on `Turn` | Role | Required |
|---|---|---|
| `agent_output` | the LLM summary (text of `gen_ai.output.messages` on the summarisation span) | yes |
| `reference` | the human reference summary, from the annotation store | yes |
| `response_id`, `conversation_id`, `trace_id`, `span_id` | correlation only, copied onto the result | recommended |

## Rule

- Extract atomic claims from the **LLM summary** (one judge call; not cached, every summary is different).
- Verify every claim against the **reference** in one judge call, under the same literal rule as capture. A claim is unsupported if the reference never mentions it or contradicts it.
- score = supported ÷ claims. Pass when score = 1.0 (configurable `threshold`): an invented clinical fact fails.

## Output

One `gen_ai.evaluation.result` event:

- `gen_ai.evaluation.score.value` — the ratio, 0.0–1.0; `gen_ai.evaluation.score.label` — `pass` if ≥ threshold (1.0) else `fail`
- `gen_ai.evaluation.explanation` — the counts and the missing / unsupported statements
- `eval.claims.total`, `eval.claims.supported` — counts; `eval.claims.unsupported` — the statements themselves, only with `capture_content=True` (member medical facts)
- errors: `missing_input` for an empty LLM summary, a missing reference, or a source with no checkable statements; `invalid_response` for a judge reply outside the schema; `timeout`, `rate_limit`, `provider_error` from the model call. On error the score attributes are omitted.

`Verdict.passed` is `label == "pass"`; the score is also recorded on the `evals.score` histogram.

## Hebrew examples

### Fail

> **Reference (human):** גבר בן 70, סוכרתי. פצע בכף הרגל שלא נרפא שבועיים. הומלץ תור דחוף לרופא משפחה.
>
> **LLM summary:** גבר בן 70 עם סוכרת ופצע בכף הרגל שלא נרפא שבועיים. מעשן. הומלץ תור דחוף לרופא משפחה.

**Verdict:** `fail` · score 0.86 — 6 of 7 claims are supported by the reference (0.86). Unsupported: 'המטופל מעשן'.

The reference never mentions smoking, so the claim is unsupported and, at the default threshold of 1.0, the summary fails.

### Pass

> **Reference (human):** ילדה בת 4. פריחה על הגוף מאתמול, ללא חום. אוכלת ושותה כרגיל. הומלץ תור לרופא ילדים מחר.
>
> **LLM summary:** ילדה בת 4 עם פריחה על הגוף מאתמול. הומלץ תור לרופא ילדים מחר.

**Verdict:** `pass` · score 1.00 — All 5 claims are supported by the reference.

Omissions do not affect precision; SummaryFactCapture catches them.
