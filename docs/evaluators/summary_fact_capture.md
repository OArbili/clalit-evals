# SummaryFactCapture

**Registry name** `summary_fact_capture` · **Type** Reference-based LLM judge, ratio score · **Module** `evals/evaluators/summary_facts.py` · **Prompt versions** `summary_facts/extract/v1`, `summary_facts/verify/v1` · **Default threshold** 0.8

## What it checks

Recall of a human reference summary by an LLM summary: the share of the reference's facts that the LLM summary states. Answers *did the LLM summary miss anything the reference says?*

## Inputs

| Field on `Turn` | Role | Required |
|---|---|---|
| `agent_output` | the LLM summary (text of `gen_ai.output.messages` on the summarisation span) | yes |
| `reference` | the human reference summary, from the annotation store | yes |
| `response_id`, `conversation_id`, `trace_id`, `span_id` | correlation only, copied onto the result | recommended |

## Rule

- Extract atomic facts from the **reference** (one judge call, cached per reference text so every summary of the same conversation is measured against the same list).
- Verify every fact against the **LLM summary** in one judge call. A fact is captured only if the summary states it or an equivalent paraphrase with the same numbers, dates, units and polarity; a changed value or a contradiction is missing.
- score = captured ÷ facts. Pass when score ≥ 0.8 (configurable `threshold`).

## Output

One `gen_ai.evaluation.result` event:

- `gen_ai.evaluation.score.value` — the ratio, 0.0–1.0; `gen_ai.evaluation.score.label` — `pass` if ≥ threshold (0.8) else `fail`
- `gen_ai.evaluation.explanation` — the counts and the missing / unsupported statements
- `eval.facts.total`, `eval.facts.captured` — counts; `eval.facts.missing` — the statements themselves, only with `capture_content=True` (member medical facts)
- errors: `missing_input` for an empty LLM summary, a missing reference, or a source with no checkable statements; `invalid_response` for a judge reply outside the schema; `timeout`, `rate_limit`, `provider_error` from the model call. On error the score attributes are omitted.

`Verdict.passed` is `label == "pass"`; the score is also recorded on the `evals.score` histogram.

## Hebrew examples

### Fail

> **Reference (human):** ילדה בת 4. פריחה על הגוף מאתמול, ללא חום. אוכלת ושותה כרגיל. הומלץ תור לרופא ילדים מחר.
>
> **LLM summary:** ילדה בת 4 עם פריחה על הגוף מאתמול. הומלץ תור לרופא ילדים מחר.

**Verdict:** `fail` · score 0.71 — 5 of 7 reference facts captured (0.71). Missing: 'למטופלת אין חום'; 'המטופלת אוכלת ושותה כרגיל'.

Two reference facts, no fever and eating and drinking normally, are absent from the LLM summary.

### Pass

> **Reference (human):** גבר בן 70, סוכרתי. פצע בכף הרגל שלא נרפא שבועיים. הומלץ תור דחוף לרופא משפחה.
>
> **LLM summary:** גבר בן 70 עם סוכרת ופצע בכף הרגל שלא נרפא שבועיים. מעשן. הומלץ תור דחוף לרופא משפחה.

**Verdict:** `pass` · score 1.00 — All 6 reference facts are captured.

The invented 'מעשן' does not affect capture; SummaryFactPrecision catches it.
