# Repetition

**Registry name** `repetition` · **Type** Deterministic · **Module** `evals/evaluators/repetition.py`

## What it checks

The agent repeated the same exact sentence. Deterministic: no model is called, so the verdict is identical on every run. Sentences end at `.`, `!`, `?` or a line break; each is normalised (leading list marker removed, whitespace collapsed, lower-cased, trailing punctuation removed) before comparison, so a repeated bullet item or line is caught as well as repeated prose.

## Inputs

| Field on `Turn` | Role | Required |
|---|---|---|
| `agent_output` | the agent's reply under evaluation | yes |
| `user_input` | not read | no |
| `history` | earlier turns; selects cross-turn mode, only assistant messages compared | optional |
| `response_id`, `conversation_id`, `trace_id`, `span_id` | correlation only, copied onto the result | recommended |

## Rule

- With an empty `history`, the reply is compared with itself: fail if any normalised sentence occurs twice.
- With a non-empty `history`, the reply's sentences are also compared with every earlier **assistant** message: fail if one of them appeared before. User messages are never compared, because a member echoing themselves is not an agent defect.
- Near-duplicates (the same sentence with one word changed) pass: the rule is exact match after normalisation.

## Output

One `gen_ai.evaluation.result` event:

- `gen_ai.evaluation.score.value` — `1` (pass) or `0` (fail); `gen_ai.evaluation.score.label` — `pass` / `fail`
- `gen_ai.evaluation.explanation` — one sentence quoting the decisive words
- errors: `missing_input` for an empty reply. Nothing else can fail: no model is called.

`Verdict.passed` is `label == "pass"`; the score is also recorded on the `evals.score` histogram.

## Hebrew examples

### Fail

> **Member:** יש לי חום 38.5 וכאב גרון מאתמול
>
> **Agent:** קבע תור לרופא המשפחה עוד היום. אם יש קושי בנשימה, פנה למיון. קבע תור לרופא המשפחה עוד היום.

**Verdict:** `fail` — The sentence "קבע תור לרופא המשפחה עוד היום" occurs twice in this response.

### Pass

Earlier turns:

> **Member:** מה שעות הפעילות של המרפאה?
> **Agent:** המרפאה פתוחה בימים א׳–ה׳ בין 8:00 ל-19:00.

The turn under evaluation:

> **Member:** ובשישי?
>
> **Agent:** המרפאה פתוחה בימי שישי בין 8:00 ל-12:00.

**Verdict:** `pass` — No sentence is repeated (cross-turn comparison over 1 sentence).

A near-duplicate of the earlier sentence is not a repeat: only the exact same normalised sentence fails.
