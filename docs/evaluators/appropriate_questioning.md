# AppropriateQuestioning

**Registry name** `appropriate_questioning` · **Type** LLM-as-judge (shared template) · **Module** `evals/evaluators/appropriate_questioning.py` · **Prompt version** `appropriate_questioning/v1`

## What it checks

When the reply asks follow-up questions, they are relevant and proportionate to the situation, rather than mechanical or interrogation-like.

## Inputs

| Field on `Turn` | Role | Required |
|---|---|---|
| `agent_output` | the agent's reply under evaluation | yes |
| `user_input` | the member's last message | yes |
| `history` | earlier turns, shown to the judge as context | optional |
| `response_id`, `conversation_id`, `trace_id`, `span_id` | correlation only, copied onto the result | recommended |

## Rule

Answer **fail** only if at least one of the following is clearly present in the latest reply; otherwise **pass**:

- A question in the reply is unrelated to the problem the user described.
- A question repeats one the user already answered in the conversation.
- The reply is a mechanical checklist: several questions at once, or a list of symptoms to tick, where one targeted question would do.
- The questions interrogate rather than help: they demand details without any acknowledgement of what the user said.

**Pre-check.** When there is no `?` in the reply, the evaluator answers **pass** without calling the model.

The judge sees the same template as every other dimension: judge only the latest reply, only this dimension, literally from the text; identical inputs must yield identical verdicts; Hebrew is judged in Hebrew and the explanation is one English sentence quoting the decisive words.

## Output

One `gen_ai.evaluation.result` event:

- `gen_ai.evaluation.score.value` — `1` (pass) or `0` (fail); `gen_ai.evaluation.score.label` — `pass` / `fail`
- `gen_ai.evaluation.explanation` — one sentence quoting the decisive words
- errors: `missing_input` for an empty reply or missing user message; `invalid_response`, `timeout`, `rate_limit`, `provider_error` from the judge call. On error the score attributes are omitted.

`Verdict.passed` is `label == "pass"`; the score is also recorded on the `evals.score` histogram.

## Hebrew examples

### Fail

> **Member:** פצעונים
>
> **Agent:** האם אחד מהבאים מתקיים? פריחה עם חום · פריחה שמתפשטת במהירות · שלפוחיות · נפיחות בפנים · קוצר נשימה · כאב חזק · הפרשה מוגלתית · חום מעל 39

**Verdict:** `fail` — The reply is a mechanical checklist of eight symptoms to tick ('פריחה עם חום · פריחה שמתפשטת במהירות · שלפוחיות …') where one targeted question would do.

### Pass

> **Member:** יש לי כאבים בבטן התחתונה
>
> **Agent:** האם את בהריון?

**Verdict:** `pass` — One targeted question relevant to lower abdominal pain ('האם את בהריון?'), not a checklist or a repeat.
